# ChatFPL X (Twitter) Apps Script

Paste `Code.gs` into your existing **ChatFPL.ai** Google Apps Script project (IFTTT watches `ChatFPL_Screenshots`).

## Schedule

- **One post per day** at **09:00** Europe/London (`postDaily` / slot 1).
- After pasting, run **`setupDailyTrigger`** once to remove old 14:00 / 19:00 triggers.

## ScreenshotOne

Shares the same API key as Instagram. Each automated run = **one** billable `/take` call.
